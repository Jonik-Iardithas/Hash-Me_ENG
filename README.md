# Hash-Me_ENG
Tool for the comparison of SHA256-Hash totals.

The internet is a dangerous place. Reports of compromised downloads are frequently making headlines in the tech news. An easy way to ensure authenticity of downloaded files is the comparison of the SHA256-Hash with the (hopefully uncompromised) original value. This can be done with just a few lines of PowerShell code. Here's an easy-to-use tool to do so. Just right-click the ps1-file and chose *Run with PowerShell*.
